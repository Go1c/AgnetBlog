# AI API Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add scoped AI token authentication and AI-facing APIs for content, search, sync, and audit inspection.

**Architecture:** AI tokens are independent from admin sessions. AI reads and writes must enforce scopes, visibility rules, validation, Git-backed metadata writes, and audit logging.

**Tech Stack:** Next.js Route Handlers, Prisma, TypeScript, crypto hashing, Git writeback services.

## Task 1: Scope Model

Create `lib/ai/scopes.ts`.

Required scopes:

- `content:read`
- `content:read-private`
- `content:write-metadata`
- `sync:trigger`
- `audit:read`

Expose helper functions for checking one or more scopes.

## Task 2: Token Hashing

Create `lib/ai/token.ts`.

Requirements:

- Generate random tokens.
- Hash tokens with `AI_TOKEN_PEPPER`.
- Store only hashes.
- Support revoke and last-used updates through the DB repository.

## Task 3: AI Guard

Create `lib/ai/guard.ts`.

Behavior:

- Read bearer token.
- Find token record.
- Reject revoked tokens.
- Enforce required scopes.
- Return AI actor context for audit logs.

## Task 4: Content APIs

Create:

- `app/api/ai/content/route.ts`
- `app/api/ai/content/[id]/route.ts`

Behavior:

- `GET` content list and detail with scope checks.
- Hide `private` content unless `content:read-private` is present.
- `PATCH` metadata only when `content:write-metadata` is present.
- Route writes through Git-backed writeback.

## Task 5: Search And Sync APIs

Create:

- `app/api/ai/search/route.ts`
- `app/api/ai/sync/route.ts`
- `app/api/ai/sync-jobs/route.ts`

Rules:

- Search respects visibility and private-read scope.
- Sync trigger requires `sync:trigger`.
- Sync job reads require a suitable read scope.

## Task 6: Audit API

Create `app/api/ai/audit-logs/route.ts`.

Behavior:

- Require `audit:read`.
- Return paginated audit logs.
- Do not expose secrets.
