# Next.js + Fumadocs Parallel Development Index

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Coordinate multiple Agents working in separate Git worktrees on the AgnetBlog v1 platform.

**Architecture:** Next.js App Router is the single runtime for the public site, admin UI, webhooks, and APIs. Fumadocs handles MDX collections and docs rendering. PostgreSQL stores derived indexes and control-plane data while GitHub remains the source of truth for Markdown metadata.

**Tech Stack:** Next.js 16, React 19, Fumadocs UI/MDX, TypeScript 5.9, Tailwind CSS 4, Prisma 7, PostgreSQL, Auth.js, GitHub API.

---

## Baseline

The base scaffold exists in the main worktree.

Verified commands:

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
```

Important baseline notes:

- Use `npm.cmd`, not `npm`, in PowerShell.
- `.worktrees/` is ignored by Git.
- `.source/` is generated by Fumadocs and ignored by Git.
- `zod` is pinned to `4.1.12`.
- `typecheck` uses an 8GB Node heap.

## Worktree Setup

Commit the baseline before starting parallel work.

Use this pattern for each Agent:

```powershell
git worktree add .worktrees/<worktree-name> -b <branch-name>
cd .worktrees/<worktree-name>
npm.cmd install
npx.cmd fumadocs-mdx
npm.cmd run typecheck
```

Each Agent must own a disjoint file set. Agents are not alone in the codebase and must not revert edits made by other Agents.
