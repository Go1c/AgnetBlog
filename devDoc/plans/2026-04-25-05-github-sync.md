# GitHub Sync Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Implement GitHub webhook sync, manual sync, and scheduled reconciliation entrypoints.

**Architecture:** GitHub events create sync jobs. Sync services fetch changed files or repository snapshots, parse Markdown through the content pipeline, and update database-derived indexes.

**Tech Stack:** Next.js Route Handlers, GitHub REST API, HMAC SHA-256, Prisma repositories, TypeScript.

## Task 1: GitHub Client

Create `lib/github/client.ts`.

Requirements:

- Read owner, repo, branch, and token from env.
- Fetch commit comparisons.
- Fetch file contents.
- List repository tree for reconciliation.
- Return typed errors without leaking secrets.

## Task 2: Webhook Verification

Create `lib/github/webhook.ts`.

Requirements:

- Verify `x-hub-signature-256`.
- Use `GITHUB_WEBHOOK_SECRET`.
- Reject missing or invalid signatures.
- Reject unsupported events.

## Task 3: Webhook Route

Create `app/api/webhooks/github/route.ts`.

Behavior:

- Verify signature against raw body.
- Accept push events only.
- Ignore pushes to non-configured branches.
- Create a `SyncJob`.
- Start incremental sync or enqueue a job depending on implementation constraints.

## Task 4: Sync Service

Create `lib/sync/sync-service.ts`.

Behavior:

- Fetch changed Markdown files when commit range exists.
- Parse content through the content pipeline.
- Upsert derived `ContentItem` records through DB repositories.
- Mark deleted Markdown as removed or unpublished.
- Record per-file failures.
- Set job status to `success`, `partial`, or `failed`.

## Task 5: Reconciliation

Create `lib/sync/reconcile.ts`.

Behavior:

- Scan repository head.
- Rebuild derived content index.
- Repair missed webhook changes.

## Task 6: Manual Sync API

Create `app/api/admin/sync/route.ts`.

Behavior:

- Require admin auth after `agent/admin-auth` is merged.
- Create a manual sync job.
- Return job id and status.
